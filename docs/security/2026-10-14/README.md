## 검증 결과의 의미

- 백엔드 전체 520/520, 별도 보안 시나리오 7/7, 프론트 인증·보안·라우팅 59/59 통과 기록을 보존했다. 프론트 전체는 395개 중 393개 통과이며 이전부터 있던 SCRAP 경계 기대값 실패 2개가 남아 있다.
- 격리된 Docker 비교에서 네 P0 영역을 다섯 시나리오로 직접 재현했다. 개선 전 5/5는 문제 재현, 개선 후 5/5는 공격 차단·정상 접근 확인이다.
- Strix는 소스 검토 후 OpenAI 가드레일로 중단됐다. 개선 후 Strix 자동 점검은 미실행이며, 검증된 발견 수는 미평가다. 자동 점검을 완료했거나 전체 사이트를 인증했다고 해석하지 않는다.
- 서비스의 유료 AI API는 가짜 제공자로 대체해 호출 0건이며, Strix 분석 모델은 실제 ChatGPT 구독을 사용했다.
- 보고서의 “미커밋·커밋하지 않음”은 점검 시점의 상태다. 이 문서 묶음은 이후 사용자가 요청한 별도 보안 브랜치의 커밋에 포함된다.

## 원본과 공개용 사본

[출판 파일 해시](./publication-manifest.json)에 로컬 원본과 저장소 사본의 SHA-256을 함께 적었다. 절대 로컬 경로를 상대 링크·기준 커밋 링크로 바꾸고, JWT·사진 URL 서명값을 가렸다. 테스트 로그는 .txt로 보존했다. 고정된 수치·HTTP 상태·시험 판정은 바꾸지 않았다. 텍스트로 보존한 재현 스크립트는 당시 Docker /app 경로와 격리 DB·가짜 제공자를 전제로 한 증거이며, 자동 운영 실행 스크립트가 아니다.

HTML 증거 화면은 파일을 내려받아 브라우저로 열면 선택과 원시 JSON 펼치기가 동작한다. GitHub는 HTML을 실행하지 않으므로 비교 이미지를 먼저 보거나, 이 폴더에서 python -m http.server 45130 --bind 127.0.0.1로 로컬 미리보기를 열 수 있다.

## 로컬에서 보관한 자료

수정 직전 전체 작업 폴더의 별도 백업은 없었다. 기준 커밋에서 만든 ZIP·소스 복사본·원시 실행 상태와 런타임은 로컬에 남겨 두었다. 저장소에는 기준 커밋·ZIP 해시와 가려진 검증 자료를 포함했다. KISA PDF 원문·추출 전문은 공식 배포처를 참조한다. 인증정보, 실제 .env, 모델 토큰, 의존성 실행 환경, Git 저장소 내부 상태는 이 묶음에 포함하지 않는다.

백엔드 기준: [dd1a433](https://github.com/goduckTeam/backEnd/tree/dd1a4333c3d64af405068b8ab35662c47854046f), 프론트 기준: [5144a45](https://github.com/goduckTeam/Frontend/tree/5144a45ea8f57f4803147dbb8b60374243967838).

## 배포 조건

두 보안 마이그레이션, AI_SESSION_STORE=database, 새 로그아웃 계약의 프론트·백 동시 적용, 업로드 프록시 우회 차단이 필요하다. 기존 길이 미확인 72바이트 경계 계정은 본인 확인을 거친 재설정 절차가 선행돼야 한다. 전체 Unicode 64자 지원·개인정보 API 전체의 캐시 통제·보안 사건 로그·대화 보관 기간·과거 디스크/백업 EXIF 정리는 남은 과제다. 자세한 계약은 [백엔드 보안 API 문서](https://github.com/goduckTeam/backEnd/blob/security/p0-hardening-20261014/docs/API_SECURITY_2026-10-14.md)에 있다.
